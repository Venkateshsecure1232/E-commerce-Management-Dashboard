# CommerceOS — E-commerce Management Dashboard

Responsive React + Vite frontend for an e-commerce admin dashboard. Includes overview analytics, product CRUD, order status management, customer CRUD, inventory alerts, search/filter/sort/pagination, CSV export, forms, confirmation dialogs, loading/empty states, toast notifications, and LocalStorage persistence.

## Run in VS Code
1. Extract the ZIP and open this folder in VS Code.
2. Run `npm install`.
3. Run `npm run dev` and open the URL shown in the terminal.
4. For a production bundle run `npm run build`.

## Demo data
Data is seeded on first load and stored in browser LocalStorage. Use the profile menu → Reset demo data to restore it. This is a frontend demo; no live backend, payment provider, or shipping integration is configured.
